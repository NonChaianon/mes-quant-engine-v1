This package implements the ratified Test 3 G3-P stage only. It creates the exact outer-
TRAIN request set before provider access, consumes `TARGET_SPACE_003` once, builds and seals
the forward realized-variance target ledger, reconciles the canonical Cell 12 path evidence,

## 4. Target and reconciliation evidence

Every outer-TRAIN parent receives exactly one target-status row. Missing path/reference is
`TARGET_UNUSABLE`; a finite zero variance is `TARGET_ZERO_VARIANCE` and triggers a terminal
stop only after the complete target ledger is sealed. Instrument/endpoint/key/order/price/
arithmetic defects fail closed immediately. No floor, clipping, imputation, annualization,
or alternate target is present.

Cell 12 must exactly cover the sealed parent set. `USABLE` paths reconcile all 60 bars,
entry and endpoint, path high/low, and long MFE/MAE on the exact 0.25-point tick grid.
`PATH_INTEGRITY_FAILURE` must reproduce the declared incomplete bar count and absent path
metrics. `LABEL_UNUSABLE` is not treated as path evidence: canonical nullable path-integrity
fields are accepted as absent, and Test 3 independently applies its own frozen
reference/raw-path target contract. Aggregate counts and hashes are persisted;
row identities and target/path values are forbidden from records.

## 5. Predictor, design, fold, and dependence evidence

The Cell 14 projection reconstructs the exact passed G2-P status ledger. Its row count,
status counts, ordered identity hash, ordered identity/status hash, and Cell 8/14 control
binding must equal committed G2-P evidence before target access.

After a nonterminal target ledger, the exact two ledgers form the sole common mask. For each
Cell 8 fold the package verifies frozen pre-eligibility holdout counts, natural-boundary
purge/gap, eligible train/holdout rows, at least 20 ordered holdout sessions, finite ordered
designs, more train rows than columns, and full rank for both frozen models. Rank uses SVD/
`matrix_rank`, never `lstsq`.

Dependence evidence uses only common-eligible OOF rows. Lags 1..8 are computed within NYSE
session for each fold and pooled disjoint OOF rows with the frozen overlap-null profile,
design effect, and ESS. These quantities are descriptive and cannot rescue or fail science;
only the structural minimums determine G3-P support.

## 6. Mechanical zero-fit guarantee

For the entire target-aware collection, the package replaces `numpy.linalg.lstsq`, `solve`,
`pinv`, `inv`, and `qr`, plus the Test 3 QLIKE, relative reduction, Duan/back-transform,
bootstrap/draw, and continuation entry points with fail-closed blockers. Every protected
symbol must exist before the guard installs. A blocked attempt raises, prevents record
publication, and appears in the typed failure boundary. SVD, `matrix_rank`, and condition
calculation remain available for structural support only. Fit, forecast, coefficient,
QLIKE, bootstrap, and economic counters remain zero.

protected safety from file presence, records Validation/Final access as fail-closed and not

with no retry. A successful aggregate record has closed top-level and nested schemas plus
bounded aggregate shapes. Evidence directories and files are durably synced, written
create-once, reread, and checked by byte and semantic hashes before success is reported.
